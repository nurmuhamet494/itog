## Описание программы

Небольшое GUI-приложение для отслеживания личных расходов.
Позволяет добавлять расходы (сумма, категория, дата), фильтровать по категории и дате,
подсчитывать сумму за выбранный период, сохранять и загружать данные в формате JSON.

**Пример:**  
*«Weather Diary — это консольное приложение для ведения дневника погоды. Позволяет добавлять записи о температуре, осадках, фильтровать их по дате и строить графики температуры.»*
