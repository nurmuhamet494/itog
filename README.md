## Описание программы

**Expense Tracker** — это десктопное приложение на Python с графическим интерфейсом (Tkinter) для учёта личных расходов. Программа позволяет:

* добавлять расходы с указанием суммы, категории и даты;
* фильтровать записи по категории и периоду;
* отображать общую сумму расходов за выбранный период;
* сохранять и загружать данные в формате JSON;
* удалять отдельные записи.

Программа полезна для контроля бюджета, анализа трат и планирования расходов.

---

## Требования для запуска

Для работы приложения необходимо:

* Python 3.6 или выше;
* стандартные библиотеки: `json`, `os`, `datetime`;
* библиотека `tkinter` (входит в стандартную поставку Python).

Установка дополнительных зависимостей **не требуется**.

## Как запустить

1. Сохраните код в файл `expense_tracker.py`.
2. Убедитесь, что у вас установлен Python.
3. Запустите приложение из командной строки:
   ```bash
   python expense_tracker.py

**Примеры использования**
**Пример 1:** Добавление нескольких расходов
Добавьте расход:

Сумма: 250.00

Категория: Еда

Дата: оставьте текущую

Нажмите «Добавить расход»

Добавьте ещё один расход:

Сумма: 50.00

Категория: Транспорт

Дата: 2026-04-25

Нажмите «Добавить расход»

Добавьте третий расход:

Сумма: 1000.00

Категория: Развлечения

Дата: 2026-05-01

Нажмите «Добавить расход»

Теперь в таблице должны отображаться все три записи.

**Пример 2: Фильтрация по категории**
В фильтре «Фильтр по категории» выберите Еда.

Нажмите «Применить фильтр».

В таблице останется только запись о расходе на еду, а сумма за период покажет 250.00.

**Пример 3: Фильтрация по периоду**
Очистите фильтр категории (выберите «Все»).

В поле «Период с:» введите 2026-04-20.

В поле «по:» введите 2026-04-30.

Нажмите «Применить фильтр».

В таблице отобразится расход на транспорт (50.00), а сумма за период будет равна 50.00.

**Пример 4: Сохранение и загрузка данных**
После добавления нескольких записей нажмите «Сохранить в JSON».

Закройте программу.

Снова запустите expense_tracker.py. Таблица будет пустой.

Нажмите «Загрузить из JSON» и выберите файл expenses.json.

Таблица заполнится ранее сохранёнными данными.
